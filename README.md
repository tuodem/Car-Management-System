# Car-Management-System
Program is based in C++ to simulate a car dealership inventory system, with queues to queue cars for service or detailing, stacks to keep track of history done within the program, linked lists for cars available at dealership, and graphs for vehicle recommendations

To run this program you must first use vs code or other ide and open the carmanagewithgraphs.cpp file within the ide.

You can also download the carmanagewithgraphs.exe executable with the file so you don't have to compile the cpp file. But if you choose not to download the executable you must type g++ carmanagewithgraphs.cpp -o carmanagewithgraphs to compile the file.

To run the executable you must type ./carmanagewithgraphs to start the program

There are tons of options in the program once you run the executable.

The program is a menu driven program you must enter a number to access each different operation.
Enter 1 which will allow user to enter the Model and make of car and the date the dealer bought the car

Enter 2 which will allow user to delete any entry in the database. It will delete the car, the date it was bought and what car was on the display

Enter 3 which will allow user to search if a car exists in the database

Enter 4 which will allow user to print what is in the database

Enter 5 which will allow user to update any element in the database

Enter 6 which will allow user to enter any car that is in the database to be put on the display for sale

Enter 7 which will print the history of the operations you have entered

Enter 8 which will delete all the history of the operations you have entered

Enter 9 which will add the vehicles you have in the database to be placed in a detail queue

Enter 10 which will access the service menu which also has its own menu with inputs such as “A” which adds cars to the service queue, “D” deletes the first car in the queue, “P” prints the entire service queue, and “Q” quits out of the service menu.

Enter 11 which will print the recommendation graph of vehicle brands and makes

Enter 12 which allows the user to access a menu to search if a car brand or make exists

Enter 13 which prints the rating of each car brand listed in the recommendation graph

Enter 14 which will exit the program
